**Congener**

Operations, compliance and environmental management for Bluff Distillery — built on Vite/React and Supabase.

**Local development**

1. Clone the repository
2. Install dependencies: `npm install`
3. Create an `.env.local` file with your Supabase project details:

```
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

4. Run the app: `npm run dev`

**Build**

`npm run build`
